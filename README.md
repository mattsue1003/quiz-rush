# ⚡ 搶答大作戰

課堂即時搶答遊戲（Kahoot 風格）。老師在電腦上主持、投影到大螢幕，學生用手機掃 QR Code 或輸入 6 位數 PIN 加入，在手機上按顏色／形狀作答。五種遊戲模式、七種題型，答得越快分數越高，每題公布答案分布、解析與排行榜，最後彩帶頒獎台與課後分析。

**線上版：** https://mattsue1003.github.io/quiz-rush/

**單一 HTML 檔、免安裝、免帳號、免後端。**

## 功能

### 遊戲模式（在大廳選擇）
| 模式 | 玩法 |
|---|---|
| ⚡ 經典模式 | 答得又快又準分數最高，連續答對加分。 |
| 🤝 團隊對抗 | 自動分成 2～4 隊，比全隊平均分；手機顯示隊伍顏色，結束時有團隊頒獎台與個人 MVP。 |
| ❤️ 生存淘汰 | 每人 1～5 條命，答錯或沒作答扣一條，淘汰後改為觀戰；只剩一人就提前結束。 |
| 🏁 極速賽跑 | 分數換算成跑道進度，每題結束看動物頭像往終點衝刺。 |
| 🎁 幸運寶箱 | 答對的人在手機上挑寶箱：加分、翻倍、偷分、和前一名交換分數、送分給別人或空箱，大螢幕即時播報。 |

### 互動與特效
- 開場模式介紹、3-2-1 倒數、「最後一題」「雙倍分數」橫幅、全對慶祝。
- 學生在等待時可送出表情（👏😂😮🔥❤️👍），會飄到大螢幕上；老師可關閉。
- 作答時大螢幕即時冒出已作答同學的頭像，最後 5 秒畫面邊框閃紅。
- 排行榜動畫換位、分數滾動、名次升降箭頭；答對時手機有彩帶與震動。
- **手機與大螢幕同步：** 模式介紹、倒數秒數、題目、排行榜、賽跑進度、生命數、隊伍都會同步顯示在手機上。
- 老師端在手機或平板上也能主持（窄螢幕自動改版面）。

### 題目
- **七種題型：** 單選、是非、複選（全對才得分）、投票（不計對錯）、簡答輸入（可設多個可接受答案，不分大小寫、全半形、空白）、**排序**（依正確順序點選，遊戲時自動打亂）、**數字**（可設容許誤差）。
- **每題設定：** 作答秒數（5～120 秒）、標準／雙倍／不計分、題目圖片（上傳自動壓縮或貼網址）、解析文字。
- **出題小幫手：**
  - 批次貼上（`|` 或 Tab 分隔，可直接從 Excel／Google 試算表複製）。
  - 匯入 CSV 檔，並可下載 CSV 範本。
  - 詞語配對自動出題：貼上「詞語 | 解釋」清單，自動產生四選一或簡答題，干擾選項從其他詞語挑。
  - 數學口算產生器：選加減乘除與數字範圍，自動出整數題（數字輸入或四選一）。
  - AI 出題提示詞：一鍵複製給 ChatGPT／Claude／Gemini，回覆可直接貼回批次貼上。
- **題庫管理：** 複製、匯出／匯入 JSON、**分享連結**（題庫壓縮進網址，其他老師點開即可匯入）。
- **範例題庫：** 台灣小常識（七種題型）、英文單字、數學速算、自然科學、成語挑戰。
- **預覽模式：** 不連線、自己先把整份測驗跑一遍，檢查題目與畫面。

### 主持（老師）
- 大廳顯示 PIN 與 QR Code，學生頭像即時出現；**點名字可移出**不恰當暱稱，可**鎖定房間**。
- 遊戲設定：隨機題序、隨機選項順序、手機是否顯示題目文字、讀題時間（0／3／5／8 秒）、是否允許中途加入。
- 讀題倒數 → 作答（背景音樂、最後 5 秒心跳倒數）→ 揭曉（長條圖、答對率、解析）→ 排行榜（名次升降箭頭、連對火焰）。
- 快捷鍵：`空白鍵`／`Enter`／`→` 進行下一步；全螢幕按鈕；音效、音樂可分別開關。
- **重新整理可恢復：** 老師不小心重新整理，首頁會出現「恢復主持」，用同一個 PIN 接續，學生自動重連，分數保留。

### 學生（手機）
- 選頭像、輸入暱稱即可加入；大按鈕作答、震動回饋。
- 每題結果顯示得分、名次，以及「距離前一名還差幾分」的追分提示。
- **斷線自動重連**，重新整理頁面也會自動接回原本的遊戲。

### 課後
- 頒獎台（第一名最後登場）與彩帶。
- 全班排名（答對率條）、題目分析（每題答對率、平均秒數、低於 50% 標示「建議再講解」）。
- 下載 CSV：每位學生每題的作答內容與對錯，以及每題統計。
- 「再玩一次」保留同一批學生。

## 計分規則
- 答對基本分 1000，依作答時間遞減，最慢也有 500 分：`1000 × (1 − 用時/限時 ÷ 2)`，雙倍分數題再乘 2。
- 連續答對：第 2 題起每題加 100，最多加 500。
- 答錯或沒作答 0 分，連對中斷；投票題不影響連對。
- 團隊模式比全隊平均分，人數不同的隊伍也公平。

## 批次出題格式
```
單選：題目 | 選項1 | 選項2 | 選項3 | 選項4 | 正確編號 | 秒數
複選：題目 | 選項1 | 選項2 | 選項3 | 選項4 | 1,3 | 秒數
是非：題目 | 對 | 錯 | 1 | 秒數
投票：題目 | 選項1 | 選項2 | 選項3 | 0
簡答：題目 | 簡答:答案1/答案2 | 秒數
排序：題目 | 排序:第一>第二>第三>第四 | 秒數
數字：題目 | 數字:100±5 | 秒數
```
選項可填 2～4 個；秒數可省略（預設 20 秒）。行首的編號或「單選：」字樣會自動去掉。格式不符的行會留在輸入框內方便修正。

## 技術架構
| 項目 | 做法 |
|---|---|
| 即時連線 | [PeerJS](https://peerjs.com)（WebRTC DataChannel）。老師的瀏覽器就是遊戲主機，PIN 即房間 ID；只有「配對」經過 PeerJS 的免費訊號伺服器，遊戲資料點對點傳輸。 |
| 題庫儲存 | 老師瀏覽器的 localStorage，可匯出 JSON 或分享連結。 |
| 遊戲狀態 | 主持端每個階段存入 sessionStorage，重新整理可恢復。 |
| 計時與計分 | 以老師端為準（主機權威），避免手機時間不一致或作弊。 |
| 音效與音樂 | Web Audio 即時合成，無外部音檔。 |

### 在本地端執行
- 下載 `index.html` 後，可以用本機伺服器開啟（例如 `python3 -m http.server`），老師就能在自己電腦上主持。
- 學生不需要連到老師的電腦：用公開網址輸入同一個 PIN 就能加入，因為配對是透過 PeerJS 的雲端訊號伺服器。
- 需要網路連線（PeerJS、QR Code 元件從 CDN 載入）。
- 題庫存在各自網址的瀏覽器儲存空間，本機版與線上版的題庫不互通，可用匯出／匯入 JSON 搬移。

### 限制與注意
- 老師端關掉分頁（不是重新整理）遊戲就結束。
- 連線靠 WebRTC，同一個 Wi-Fi 下最穩；若校園網路封鎖 WebRTC 或 PeerJS 訊號伺服器會連不上。需要時可改接 Firebase，訊息收發集中在 `broadcast / sendTo / onHostData / onPlayerData`。
- 建議人數 60 人以內。題庫有圖片時，瀏覽器儲存空間約可放數百張壓縮後的圖。
- 分享連結不含「上傳」的圖片（網址圖片會保留）；要完整分享請用匯出 JSON。
