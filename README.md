# ⚡ 搶答大作戰

課堂即時搶答遊戲（Kahoot 風格）。老師在電腦上主持、投影到大螢幕，學生用手機掃 QR Code 或輸入 6 位數 PIN 加入，看大螢幕的題目、在手機上按顏色／形狀作答。答得越快分數越高，連續答對有加分，每題結束公布答案分布與排行榜，最後頒獎台。

**單一 HTML 檔、免安裝、免帳號、免後端。**

## 怎麼用

### 老師
1. 開啟網頁 → 「進入老師後台」。
2. 「＋ 新增測驗」手動出題，或「📋 批次貼上題目」一次貼多題（格式見下）。
3. 回到題庫按「▶ 開始遊戲」，大螢幕顯示 PIN 與 QR Code。
4. 學生加入後按「開始」。每題結束 → 「排行榜」→「下一題」。
5. 結束畫面可「下載成績 CSV」（含每題對錯），或「再玩一次」。

### 學生
開啟同一個網址（或掃 QR）→ 輸入 PIN 與暱稱 → 加入。手機掉線重開頁面，用同一個暱稱重新加入，分數會保留。

### 批次出題格式
每行一題，用 `|` 分隔：
```
題目 | 選項A | 選項B | 選項C | 選項D | 正確選項編號(1-4) | 秒數
```
選項可只填 2～4 個，秒數可省略（預設 20 秒）。可以請 AI 依這個格式幫你出題再貼進來。

## 計分規則
- 答對基本分 1000，依作答時間遞減，最慢也有 500 分：`1000 × (1 − 用時/限時 ÷ 2)`
- 連續答對：第 2 題起每題加 100，最多加 500。
- 答錯或沒作答 0 分，連對中斷。

## 技術架構
| 項目 | 做法 |
|---|---|
| 即時連線 | [PeerJS](https://peerjs.com)（WebRTC DataChannel）。老師的瀏覽器就是遊戲主機，PIN 即房間 ID；學生端直接連到老師端。只有「配對」經過 PeerJS 的免費訊號伺服器，遊戲資料點對點傳輸。 |
| 題庫儲存 | 老師瀏覽器的 localStorage，可匯出／匯入 JSON 備份或換電腦。 |
| 計時與計分 | 以老師端為準（主機權威），避免手機時間不一致或作弊。 |
| QR Code | qrcodejs，由目前網址加上 `?pin=` 產生。 |
| 音效 | Web Audio 即時合成，無外部音檔。 |

### 限制與注意
- **要放到網路上**（例如 GitHub Pages）手機才連得到；直接開本機檔案只能在同一台電腦試玩。
- 老師端分頁關掉、重新整理，遊戲就結束（主機在瀏覽器裡）。進行中會跳出離開確認。
- 連線靠 WebRTC，同一個 Wi-Fi 下最穩；若校園網路封鎖 WebRTC 或 PeerJS 訊號伺服器，會連不上。需要更高可靠度時，可改接 Firebase Realtime Database（架構已把訊息收發集中在 `broadcast / sendTo / onHostData / onPlayerData`，替換傳輸層即可）。
- 建議人數 60 人以內（每位學生一條 P2P 連線）。

## 部署到 GitHub Pages
1. 建一個 repo，把 `index.html` 放在根目錄。
2. Settings → Pages → Source 選 `main` / root。
3. 網址會是 `https://<帳號>.github.io/<repo>/`，學生用這個網址加入。

## 檔案
- `index.html`：全部程式（老師後台、編輯器、主持端、學生端）。
